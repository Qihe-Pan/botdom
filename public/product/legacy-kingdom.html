Independent review

Another member reviews the work. A pass is still an AI judgment, not your approval.

Sample

Review passed

Delivery and review are two separate records.

What the review labels mean
Review passed
The reviewer checked the work against the requirements.
Review failed
Changes are needed. Work that depends on the reviewed draft won't treat it as passed.
Review blocked
The reviewer couldn't finish the check.
Record needs checking
The result can't be confirmed yet. Check it in the original group.

VThe Gatehouse

Stay in charge while they work.

  • Queue

    Add work while a Bot is busy. Edit, reorder or cancel what's waiting.

  • Pause

    Holds follow-up work. A running step can still finish.

  • Stop

    Ends the work. Doesn't undo changes.

  • Restarts

    Pause and stop survive a restart. Unclear results get checked, not rerun.

  • Approvals

    Permission requests show up in the chat.

Before you start

New Bots start with Full Access

New Codex, DeepSeek Harness and OpenCode Bots start with Full Access. Give them tasks you trust, and keep backups.

XThe Notice Board

Short answers.

Does Botdom run in the cloud?

No. It runs on your computer. Work stops if the computer sleeps or the backend stops.

Which tools can join a group?

Codex, OpenCode, DeepSeek Harness, Claude Code and CodeBuddy Code. You install and configure each one yourself.

Do members see all my chats?

No. Each chat has its own session. Reading other records needs your say-so.

Can members use different models?

Yes, per Bot and per group, within the accounts you've set up.

Is it safe to let Bots work on my computer?

Use care: new Bots start with Full Access, and stopping doesn't undo changes. Keep backups.

Is the sample meeting on this page real?

No. It's an illustration. No models are called.
